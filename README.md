# Seguridad y protección del dispositivo

Guía práctica, paso a paso y bilingüe (español / inglés), para que cualquier persona sin conocimientos técnicos pueda proteger su ordenador y su móvil.

Proyecto de documentación técnica realizado con **MkDocs (tema Material)** y publicado con **GitHub Pages**.

## Cómo ver el sitio en tu ordenador

```bash
pip install -r requirements.txt
mkdocs serve
```

Después abre <http://127.0.0.1:8000> en el navegador.

## Cómo publicar los cambios

```bash
mkdocs gh-deploy
```
