# Secure Wi-Fi

## The problem with public Wi-Fi

Wi-Fi in cafés, airports or hotels is used by many people. Some may be poorly protected or even **fake** (a criminal creates a network with a similar name to spy on you).

!!! warning "Golden rule"
    On public Wi-Fi **don't log in to your bank or shop online**. For that, use your phone's mobile data.

## How to protect your home Wi-Fi

### Step 1: change the router password

The router (the little box that gives you internet) comes with a factory password. It is usually on a sticker. **Change it** to a [strong password](contrasenas.md).

1. Type the router's address in the browser (usually `192.168.1.1`; check the sticker).
2. Log in with the username and password on the sticker.
3. Look for **Wi-Fi** or **Wireless security**.
4. Change the password and the network name.

### Step 2: use modern encryption

On the same screen, look for **Security** or **Encryption** and choose **WPA3**. If your router doesn't have it, choose **WPA2**. **Never choose** WEP or "No security".

| Type | Is it safe? |
|---|---|
| WPA3 | ✅ Yes, the best |
| WPA2 | ✅ Yes, acceptable |
| WEP | ❌ No, it breaks in minutes |
| No password | ❌ No, anyone gets in |

### Step 3: don't publish your family name

Don't put your name or flat number in the network name (for example, `Smith_Family_3B`). Use a neutral one.

## When you are away from home

- Confirm the exact network name with the venue (ask the staff).
- Prefer **mobile data** for important operations.
- Turn off **automatic connection** to public networks.
- Use pages that start with `https://` and show a padlock.

=== "Windows"

    1. Open **Settings → Network & internet → Wi-Fi**.
    2. Go to **Manage known networks**.
    3. Remove the public networks you don't use.

=== "macOS"

    1. Open **System Settings → Wi-Fi**.
    2. Click **Advanced**.
    3. Remove public networks from the list of known networks.

- [ ] I have changed the router password

- [ ] I avoid banking on public Wi-Fi

??? question "What is a VPN?"
    A tool that **encrypts** what you send, like a private tunnel. It helps on public networks, but doesn't replace the other measures. If you use one, pick a trustworthy one.

??? question "How often should I change the Wi-Fi password?"
    If it is strong, it is enough to change it if you suspect someone knows it or you have shared the network with many people.
